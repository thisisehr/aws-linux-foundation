AWS DevOps and Deployment Services

DevOps

DevOps is a practice that combines development and operations to improve software delivery and automation.


Benefits of DevOps

- Faster deployment
- Improved collaboration
- Automation
- Continuous monitoring
- Reduced downtime


CI/CD

CI
Continuous Integration.

CD
Continuous Delivery or Continuous Deployment.

Purpose

Automates building, testing, and deployment of applications.


CodeCommit

AWS managed Git repository service.

Features

- Secure source control
- Version management
- Team collaboration


CodeBuild

Build service used to compile source code and run tests.


CodeDeploy

Automates application deployment to EC2 and other services.


CodePipeline

Automates the CI/CD workflow in AWS.


Elastic Beanstalk

Platform as a Service used for deploying applications quickly.

Features

- Automatic scaling
- Load balancing
- Monitoring support


CloudFormation

Infrastructure as Code service in AWS.

Purpose

Used to create and manage AWS resources using templates.


YAML

Human-readable data format used in CloudFormation templates.


JSON

Data format used for configuration and policies.


Docker

Containerization platform used to package applications.

Benefits

- Lightweight
- Portable
- Faster deployment


Container

Isolated environment used to run applications.


ECR

Elastic Container Registry used to store Docker images.


ECS

Elastic Container Service used to run containers in AWS.


EKS

Elastic Kubernetes Service used to manage Kubernetes clusters.


Lambda

Serverless compute service in AWS.

Features

- No server management
- Automatic scaling
- Pay only for usage


Serverless Computing

Applications run without managing servers.


API Gateway

Used to create and manage APIs for applications.


Monitoring in DevOps

CloudWatch
Used for monitoring AWS resources and applications.

SNS
Used for notifications and alerts.
