AWS Storage and Database Services

S3

S3 stands for Simple Storage Service.
It is used for storing files and objects in AWS.

Features of S3

- Highly scalable
- Secure storage
- High durability
- Easy backup and recovery

Bucket

Container used to store objects in S3.

Object

A file stored inside an S3 bucket.

Storage Classes

Standard
Used for frequently accessed data.

Standard-IA
Used for infrequently accessed data.

Glacier
Used for long-term archive storage.


EFS

EFS stands for Elastic File System.
Provides scalable shared file storage for Linux instances.

Features

- Shared storage
- Automatic scaling
- Accessible from multiple EC2 instances


FSx

Provides fully managed file systems in AWS.

Types

- FSx for Windows
- FSx for Lustre


RDS

RDS stands for Relational Database Service.
Provides managed relational databases in AWS.

Supported Databases

- MySQL
- PostgreSQL
- MariaDB
- Oracle
- SQL Server

Features of RDS

- Automated backups
- High availability
- Automatic patching
- Scalability


DynamoDB

NoSQL database service in AWS.

Features

- Fully managed
- High performance
- Automatic scaling


Redshift

Data warehousing service used for analytics and reporting.


AWS Backup

Used to centrally manage backups of AWS resources.


Lifecycle Policy

Used to automatically move objects between S3 storage classes.


Versioning

Used to maintain multiple versions of objects in S3 buckets.


Encryption

Used to protect AWS storage and database resources.

Types

Server-Side Encryption
Encryption managed by AWS.

Client-Side Encryption
Encryption managed by the user.
