ls
Lists files and directories.

cd
Used to change directories.

cat
Displays the content of a file.

clear
Clears the terminal screen.

cp
Copies files or directories.

mv
Moves or renames files.

pwd
Shows the present working directory.

whoami
Displays the current logged-in user.

date
Shows the current date and time.

cal
Displays the calendar.

man
Displays the manual page of a command.

history
Shows previously used commands.

chmod
Changes file permissions.

chown
Changes file ownership.

find
Searches for files and directories.

grep
Searches text patterns inside files.

top
Displays running processes and system usage.

ps
Shows currently running processes.

kill
Terminates a process using process ID.

df
Displays disk space usage.

free
Shows memory usage.

ping
Checks network connectivity.

Networking Commands

ifconfig
Displays network interface information.

ip a
Shows IP address details.

ping
Checks connectivity between systems.

netstat
Displays network connections and listening ports.

ss
Displays socket statistics.

curl
Transfers data from or to a server.

wget
Downloads files from the internet.

hostname
Displays the system hostname.

nslookup
Finds DNS information of a domain.

traceroute
Shows the path packets take to a destination.


Compression Commands

zip
Compresses files into a zip archive.

unzip
Extracts zip archive files.

gzip
Compresses files using gzip format.

gunzip
Decompresses gzip files.

tar
Creates or extracts archive files.


Basic Shell Scripting

#!/bin/bash
Defines the script interpreter.

echo
Displays output in the terminal.

read
Takes input from the user.

Variables
Used to store values inside a script.

if
Used for conditional statements.

for
Used for looping operations.

while
Executes commands repeatedly based on a condition.

chmod +x filename.sh
Makes a shell script executable.

./filename.sh
Runs the shell script.
