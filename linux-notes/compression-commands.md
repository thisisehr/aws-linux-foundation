tar -cvf
Creates a new tar archive.

tar -xvf
Extracts files from a tar archive.

tar -czvf
Creates a compressed tar.gz archive.

tar -xzvf
Extracts a tar.gz archive.

zip -r
Compresses folders recursively.

unzip filename.zip
Extracts a specific zip file.

gzip filename
Compresses a file.

gunzip filename.gz
Decompresses a gzip file.
