User Management Commands

useradd
Creates a new user.

passwd
Sets or changes a user password.

su
Switches to another user.

sudo
Executes commands with administrative privileges.

whoami
Displays the current logged-in user.

id
Displays user and group IDs.

userdel
Deletes a user account.

groupadd
Creates a new group.

groupdel
Deletes a group.

usermod
Modifies user account details.

groups
Displays groups of a user.

chage
Changes password expiry information.

last
Displays recently logged-in users.

finger
Displays information about users.


Examples

sudo useradd eshwar

sudo passwd eshwar

su eshwar

sudo userdel eshwar

sudo groupadd developers
